# Stand-in stock images and videos

These are used only for the local design preview, until the client sends real photos and videos. They are listed in `scripts/stock/stock-images.json`, downloaded and converted by `npm run stock`, and stored in `public/demo/`. The local demo database (`seeds/demo-local.sql`) points the Home page at them. Replace them from the admin dashboard before launch.
